## 1. 目标

在求职作战台新增「简历」板块（路由 `/resume`），实现：

1. **素材库**：所有经历/技能/证书/招聘软件字段统一管理，网页直接编辑；
2. **多版本**：量化岗版、视觉算法岗版等，标签页一键切换，页面直接展示该版本完整简历内容；
3. **版本挑选**：每个版本从素材库挑选/排序/微调，改一次素材可同步多处；
4. **导出**：按版本导出，默认 PDF，同时支持 Markdown / HTML / 纯文本；
5. **AI 联动**：把某段经历改写成目标岗位语言，一键替换或另存。

### 2.1 版本标签页
- 顶部 Tab：`量化岗版`、`视觉算法岗版`、`＋ 新建版本`（自定义名称与目标岗位）。
- 切换 Tab 即整页切换为该版本的完整简历文档（**需求：直接展示完整简历**）。
- 未选中的板块/条目在本版本中隐藏，不展示（保持"简历即成品"的观感）。

### 2.2 每块可编辑（核心交互）
- 简历文档中每个板块、每条经历都是**行内编辑**：点击即变为表单（文本框/多行文本/结构化字段），保存即写入素材库。
- 版本内微调：某条经历可在当前版本内改标题/描述（作为**版本覆盖**），带「已定制」标记；可一键恢复素材原文。
- 板块级操作（⋯ 菜单）：在本版本中显示/隐藏、上移/下移、从版本移除。
- 条目级操作：在本版本中包含/排除（如量化版排除 FD-BEVFusion 的视觉细节、算法版排除量化数字）。

### 2.3 素材库抽屉
- 左侧/底部抽屉列出全部素材，按分类（基本信息/教育/实习/项目/技能/证书/自我评价/求职意向/附件）。
- 每项标注引用它的版本；编辑素材 = 全局更新，所有未覆盖的版本同步。
- 「AI 改写」：选中素材 → 选择目标风格（量化岗语言 / 视觉算法岗语言）→ AI 生成 → 预览 → **应用到当前版本**（版本覆盖）或**更新素材**（全局）或另存为新素材。

## 3. 数据模型

```ts
// 素材（单一数据源）
interface ResumeMaterial {
  id: string;
  category: 'basic' | 'jobIntent' | 'education' | 'experience'
          | 'project' | 'skill' | 'honor' | 'selfIntro' | 'attachment';
  title: string;            // 板块内条目标题（如 "A股多因子选股策略"）
  fields: Record<string, string>; // 结构化字段（时间/公司/角色/描述列表…）
  content: string[];        // 要点列表（bullet 行）
  tags: string[];           // 素材标签（量化 / 视觉 / 通用）
  aiVariants?: { quant?: string; vision?: string }; // 可选：AI 改写变体缓存
  createdAt: number;
  updatedAt: number;
}

// 版本（挑选与定制）
interface ResumeVersion {
  id: string;
  name: string;              // "量化岗版"
  targetRole: string;        // "量化研究实习生 / 量化开发实习生"
  jobIntent: {               // 招聘软件字段（可版本独立）
    city: string; expectSalary: string; availability: string; ...
  };
  blocks: Array<{
    materialId: string;
    order: number;
    visible: boolean;        // 是否纳入本版本
    override?: Partial<ResumeMaterial>; // 版本内微调（已定制标记）
  }>;
  attachment: { fileName: string; fileUrl: string } | null;
  createdAt: number;
  updatedAt: number;
}

// 持久化：localStorage（key: jobhunt-ops-resume-v1）+ Firebase 云同步（登录时并入 states/{uid}）
```

## 4. 导出

| 格式 | 用途 | 实现 |
|---|---|---|
| **PDF（默认）** | 投递附件 / 上传招聘网站 | 版本文档按简历样式渲染 → `window.print()` 打印样式导出 PDF |
| Markdown | 存档/再编辑 | 按版本内容生成 `.md` 下载 |
| HTML | 网页版简历 | 按版本生成单文件 `.html` |
| 纯文本 | 粘贴进招聘软件表单 | 生成无格式 `.txt` 复制/下载 |

- 导出按钮在版本标签页右上角，作用于**当前版本**。

## 5. AI 联动设计

- 复用现有 DeepSeek 安全代理（`src/services/ai/DeepSeekAdapter.ts`），新增「经历改写」能力；
- 流程：选中素材条目 → 点「AI 改写」→ 选择目标风格（量化岗语言 / 视觉算法岗语言 / 通用）→ 服务端生成改写稿 → 前端预览对比（原文 vs 改写）→ 用户选择：应用到当前版本 / 更新素材 / 另存为新素材 / 放弃；
- 安全模型沿用现状：密钥只在服务端、只发送勾选的最少上下文、生成一律是草稿、写入必须确认。
